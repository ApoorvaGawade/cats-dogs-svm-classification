\## Approach

\- Image preprocessing

\- Feature extraction (HOG / flattening)

\- SVM classification



\## Dataset

\- Kaggle Cats vs Dogs dataset

\- Dataset not included due to size constraints



\## Tools \& Libraries

\- OpenCV

\## Result

SVM successfully classified cat and dog images with good accuracy.
